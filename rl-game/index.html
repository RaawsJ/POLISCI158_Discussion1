A small, inspectable state space

288 table states = 36 squares × 2³ vote combinations. Three bits record whether A, B and C have been secured. D is loyal and needs no bit. Four actions give 1,152 Q-values. Some table states are unreachable, such as standing on an unsecured wavering member.

The clock is a teaching simplification

The agent sees only its square and secured votes, as requested. Moves remaining are excluded, so the same table state can have different time left. This is a time-aliased approximation to a finite-horizon task, not a fully Markov state. The 15-move limit is enforced in every game.
